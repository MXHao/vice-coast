# 热湾狂飙：从 R39 恢复 R45 公开试玩版

这是**源码增量**，不是可直接启动的游戏。它用 R39 的公开静态文件与两件现成角色资源，重建 R45 的游戏脚本和入口页；不需要把 R45 已构建的游戏脚本或入口页当输入。

## 准备两个输入目录

1. **R39 静态目录**：须是完整的 58 个文件，65,383,272 字节。若手上只有相应的 R38 发行版，可先按同级 `../r39-runtime/` 的说明重建 R39。R39 的 `index.html` SHA-256 是 `adae085322eddfb5cdacf762b00fcf5313ac7da2b7be2bff37c1c64722df3d37`。
2. **角色资源目录**：从已经发布的 R45 试玩版取得下列两个 `assets/` 文件，保留原名并放在同一目录。每个文件名中间的 64 位十六进制串就是它的 SHA-256。脚本只读这两个指定文件，不复制该目录的其他内容。

```text
hero-d08167aa6170fdff41c70172c329a7693388ffd90fe8dea0be4ef088aea64e85.js
crouch-c8d001e365522b44a1964684c62e5db0475d8cacb1edcced285d0fa79f5e96e2.js
```

## 重建与校验

只需要 Python 3.9+ 标准库。将下列示例路径换成自己的；输出必须是尚不存在的目录，不要选在输入目录或配方目录内。脚本不联网、不安装依赖、不发布。

```sh
python3 recover.py build /path/to/r39-dist /path/to/character-assets /path/to/new-r45-dist
python3 recover.py verify /path/to/new-r45-dist
```

重建先检查 R39 的文件名和每个文件内容，在内存中重建并核对 R44，再替换成 R45 的蹲姿动作、按需加载器和公开试玩提示。R39 的样式与 55 个视图资源共 56 个文件保持原样。

**预期结果：60 个文件，74,311,392 字节。** 入口页 SHA-256 为 `f11a0bd83570c72f15af7ef3a35b63e563952d60641cbbd82a21fb9c620bbfc7`；游戏脚本 SHA-256 为 `22556e84b6b71a8829de8240de338d1f72198b87182aa2db772e3d0a0c773970`。完整清单的 SHA-256 为 `487bd69f12af519dd3f767118d6f17988272ff2c41ea62f24686f25be06c2a35`：按相对路径排序，每行写入“文件 SHA-256、两个空格、路径、LF”，不把清单本身算作发行文件。`verify` 可独立检查现成目录；多余、缺少或被改动的文件都会使校验失败。

## 源码范围

- `r44-gait.js`、`r44-player.js`、`r44-boot.js`：站姿运动相位、人物显示切换与按需加载。
- `r45-stance.js`、`r45-player.js`、`r45-boot.js`：蹲下和起身的相位衔接、玩家显示逻辑与蹲姿资源加载。
- `r45-adapter.js`：已发布蹲姿资源内的骨骼与服饰适配函数。重建时核对适配函数与指定资源一致；不会从它生成网格或动作数据。

本目录不含游戏整包、音频、角色模型、动作素材或第三方引擎。没有前述输入就不能仅凭这份源码恢复完整游戏。原有署名和许可随基线保留；能够重建不代表获得再分发素材的授权。验证针对静态文件字节，不替代浏览器或真机试玩。
