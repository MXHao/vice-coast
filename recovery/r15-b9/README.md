# Vice Coast R15 B9 source recovery
This independent source backup builds all 56 game items and the stock R14 follow-up fixes: default mouse look, stock wardrobe binding and vehicle engine sound.
Place the separately retained exact baseline at repository-root vendor/R11.html as documented in vendor/README.md. Use Node 24.22.3.
From this directory run:
```sh
node --expose-internals tools/build-stock-core.mjs
node --expose-internals --test tests/*.test.mjs
```
The default builds out/stock-core-source-only.html. This build's SHA-256 is 2f071d7049472f74f4f1736b1cdedf8a7a1d2cfb0c19e2350a7a7bd0e529e4c6.
This is not the independent release soundtrack. Twelve original Vice Coast cues are regenerated by source; the other 44 are silent for the armory-specific action and do not offer an audition. The rejected variant is deliberately excluded. The release uses separately provisioned audio, not distributed in this source checkpoint, so this source-only file will differ from the playable website.
Keep build output, baseline HTML, audio input and any local game data out of Git.
