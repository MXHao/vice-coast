# 热湾狂飙 R39：运行时代码增量

这是一个**离线恢复配方**，不是可以直接游玩的整包。它按 R39 发布时的顺序，把四组源码应用到**持有人自行提供的、逐字节匹配的 R38 三文件发行版**：

1. `economy/`：将自由漫游的钱包、存档与剧情分开。
2. `racing/`：加入两圈、四名对手的环线竞速和比赛菜单。
3. `first-person/`：桌面第一人称切换、画面过渡、输入与界面提示。
4. `loading/`：拆分启动资源，延后读取 55 个可选视图文件。

R38 文件不随本目录提供。源配方不包含游戏媒体、用户存档、录音、模型、第三方引擎包或已构建的发布文件。构建时从本地 R38 继承其原有内容及声明；可复现不等于有权重新分发这些内容。本配方不会联网、安装依赖或部署。

## 输入

需要 Python 3.11+ 和 Node.js（已在 Python 3.12、Node.js 24 验证）；都只用标准库。基线目录应恰好包含以下三个文件；第二、三行文件名中的完整 64 位十六进制串就是对应文件的 SHA-256。

```text
index.html  [SHA-256: 9b95774afe01af62e414c5792345a1820a85eca191ea033ed104d7bf40dac52b]
assets/r38-art-0-5d65b2ded64d72b7c196308dbda730be027b384d22fa2ea0409d68a2f3adbdcd.js
assets/r38-art-1-48b194547dc387e2fc8e32b3dd5a52f4945f97bf02a056e36b3ade0b7a4b7c2b.js
```

## 构建与独立校验

在本目录执行。请把两个示例路径换成自己的路径：输入与输出都应在仓库外；输出目录必须尚不存在，但其上级目录必须存在。临时文件在构建结束时清理。

```sh
python3 compose.py build /path/to/r38-dist /path/to/new-r39-dist
python3 compose.py verify /path/to/new-r39-dist
```

成功结果是 **58 个文件，共 65,383,272 字节**。除了核对下列三个核心文件的 SHA-256，校验器还核对 55 个可选文件的完整路径集合及每个文件内容的 SHA-256；缺失、多余或被改动的文件都会导致失败。

| 核心文件 | 字节数 | SHA-256 |
| --- | ---: | --- |
| `index.html` | 56,192 | `adae085322eddfb5cdacf762b00fcf5313ac7da2b7be2bff37c1c64722df3d37` |
| `assets/game-<SHA-256>.js` | 20,806,191 | `28c02bd67edb236da95a2e2b9e84a058a1c9935fa517b625ff4310ee24970536` |
| `assets/layout-<SHA-256>.css` | 937,533 | `c6f56aacda1f8d45ff237984991602707d686fb177df82708b85e6ddf297da7b` |

这个校验针对 R39 的静态文件字节，不是浏览器、显卡或在线服务的运行状态检查。
